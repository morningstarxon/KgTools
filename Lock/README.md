# KgLock - Locks your computer with the press of a key
Use your bluetooth device's play-pause button to lock your computer from far away! IMPORTANT: Especially with headphones or earbuds, the play-pause button may not be named as it is in the script! If the script doesn't work for some reason, please go to KeyLogger and press your key to see which one it is.
ALSO VERY IMPORTANT: do "pip install pynput" or it will automatically close.
